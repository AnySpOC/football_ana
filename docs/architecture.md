# Architecture

> この文書は初期プロトタイプの構成メモです。見直し後の設計は
> [Football Ana システム設計書 v2](./system_design_v2.md)を参照してください。

## 基本方針

最初のプロトタイプでは、動画アップロード、解析ジョブ、JSONサマリ、動画オーバーレイ表示の流れを優先します。検出・追跡・イベント推定は段階的に差し替えられるように、`backend/app/services/analyzer.py` に集約しています。

## 解析パイプライン

1. フレーム抽出
2. 人物検出
3. ボール検出
4. 選手追跡
5. ユニフォーム色抽出
6. チーム分類
7. 座標のピッチ平面変換
8. 移動距離、ポゼッション、パス、シュート推定
9. JSONとオーバーレイ動画を出力

## 推奨モデル

- 人物・ボール検出: YOLO系モデル
- 追跡: ByteTrackまたはDeepSORT
- 姿勢推定: YOLO PoseまたはMediaPipe
- 個人識別: 背番号OCR、ReID特徴量、移動軌跡の組み合わせ

## データセット候補

- SoccerNet
- DFL Bundesliga Data Shootout
- Roboflow Universeのsoccer ball/player系データ
- 自前撮影動画にアノテーションを追加したデータ

## 精度改善ポイント

- 競技ごとにフィールドサイズを設定する
- カメラ視点をキャリブレーションする
- ボール検出モデルは小物体に強い設定で再学習する
- ユニフォーム色分類はHSV色空間とクラスタリングから始める
- 個人識別は背番号が見える場面だけ高信頼度として扱う
